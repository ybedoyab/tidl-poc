# References

Tracked literature lives in [bibliography.bib](bibliography.bib). Citing a
paper is **literature evidence**. It is not a local reproduction and not a
physical measurement by this project.

## Local papers

Place locally obtained PDFs in `private/`. That directory is gitignored except
`.gitkeep`. Do not commit copyrighted or paywalled PDFs.

## Using entries

Each BibTeX `note` field records why the paper is tracked and which claim
class it may support. Submission text must still pass through
[docs/competition/claims-register.md](../docs/competition/claims-register.md)
before a number is treated as safe to use as *this project's* result.

IEEE 1139 and NIST SP 1065 are standards/method references for ADEV/MDEV/TDEV
definitions. This repository does not yet contain measured stability datasets.
